# Reconciliation review — architecture invariants vs inputs

Target: `technical-note-architecture.md` (TN), section "Architecture invariants" (AD-1 to AD-11, diagram, stack seed, Deferred) and the rest of the note. Date: 2026-10-10. Read-only review; nothing else was changed.

Only findings are listed. Decisions that landed cleanly are not repeated: one engine (AD-1), REST not exposed (AD-4), in-memory rate limit (AD-10), hybrid recompute (AD-6), schemas and grants (AD-3), seed tags (AD-9), local-only deployment (Deferred), pinned model id and test mode (AD-7), FR-69 URL state (AD-5), FR-20/FR-59 no extraction or model call in a request.

Where one finding touches several inputs, it is listed in full once and the other lists point back to it with "(see …)".

## 1. PRD (`prds/prd-Peerless-2026-09-25/prd.md`)

- [contradicts] Stored explanations for 62.100 companies outside the demo set. FR-73 "Concretely" bullet says *"no stored explanation exists, and the page says so"*. FR-73's seed bullet, the memlog and AD-7 say the opposite: an explanation is generated for every 62.100 company, citing only API figures (FR-73 seed bullet and "Concretely" bullet → AD-7, TN "Running locally" / "AI in test mode"). The PRD contradicts itself, and EXPERIENCE follows the losing side. Suggested fix: keep the memlog decision (AD-7). Rewrite FR-73's "Concretely" bullet and EXPERIENCE's outside-seed row so the explanation is shown, built from API figures only. Or, if the explanation should be withheld, narrow AD-7 and the memlog to the demo companies.
- [contradicts] The responsive check must happen during development (FR-55 consequence "Checked at phone width during development, not at the end"; §7 "Accessibility and responsiveness" → TN "Schedule" week 9 "Responsive pass"). Suggested fix: change week 9 to "final 320/375 px audit". State that every UI story's acceptance includes a 375 px check (and the 320 px floor from EXPERIENCE).
- [contradicts] Non-calendar financial years. FR-8 says only calendar-year filings pass; `docs/key-figures.md` says the same (FR-8 → TN "Calculation engine": *"Deviating or changed financial years are excluded or adjusted explicitly"*). Suggested fix: replace with "Non-calendar and changed financial years are excluded by the comparability filter (FR-8); nothing is adjusted."
- [dropped] Engine reference cases must include a non-calendar financial year (§7 "Calculation integrity", SM-6 → TN "Test strategy", reference cases list, which names only negative equity, zero revenue and missing components). Suggested fix: add the case to the list, written as a case asserting exclusion, so it agrees with FR-8.
- [dropped] Two authorisation patterns are missing: "calling an endpoint unauthenticated" and "reading another user's data" (§7 "Authorisation" → TN "Test strategy", authorisation tests). Suggested fix: add both to the TN list. This is stage 2, but the list is what stories will copy.
- [dropped] Tests the PRD makes load-bearing are missing from the TN: the two-cluster no-double-counting assertions (FR-30, SM-6), the two exact identities (FR-21), the per-industry within-band spread test (FR-13), and "no loosening admits a comparability failure" (FR-18) (→ TN "Test strategy", and Deferred "AD-6, AD-7 and AD-9 name the tests that must exist"). The Deferred line reads as if those three ADs list every required test. Suggested fix: add one line to "Test strategy" listing the PRD-mandated tests by FR. Reword the Deferred line to "in addition to the FR-mandated tests".
- [dropped] Two FR-73 tests are missing: a test asserting no request to the register or a model leaves the app during an analysis, and a test that loading the seed twice leaves the same state (FR-73 "No runtime dependency", "Seed data, one command" → nowhere in TN). Suggested fix: put the network-isolation test under AD-7 and seed idempotence under AD-9.
- [dropped] FR-54 (explains, does not recommend) is missing from AD-7, which binds FR-52, FR-53 and FR-73. No mechanism is named anywhere in the TN. Suggested fix: add FR-54 to AD-7's Binds. State the mechanism (generation prompt constraint plus a reviewed sample at generation time). Also state that it is not test-enforced, unlike FR-53.
- [ok-with-note] FR-52 requires every figure in the text to link to its calculation. FR-53 rejects a right number attached to the wrong key figure, company, year or direction (FR-52, FR-53 → AD-7 says only "FR-53 runs"). Both require a structured stored format, and AD-7 does not fix one. Suggested fix: AD-7 stores each explanation as text with slot references to engine output ids (figure, company, year, direction). The renderer turns slots into links, and FR-53 checks the binding as well as the value.
- [ok-with-note] Per-IP refusal behaviour is under-specified (FR-6 "Exceeding the limit returns a refusal, not a degraded or partial analysis" → AD-10). AD-10 says how the counter is held but not what counts, or what a refusal returns. Suggested fix: AD-10 states that page renders, exclude/widen renders and search queries all count, possibly in separate budgets (see EXPERIENCE). A refusal renders the refusal state with no figures.
- [ok-with-note] The TN cannot tell three different absences apart: own filing failed reconciliation (FR-71), undefined (FR-23), and not in the demo seed (FR-73 "Ikke i demodataene") (FR-71, FR-23, FR-73 → AD-9 tags rows but says nothing about the read path). With `seed:full` loaded, "Ikke i demodataene" must never appear. Suggested fix: add to AD-9 that the loaded seed level is recorded in the database. Each filing stores its reconciliation status. The renderer derives the reason from those two, never from the row being absent.
- [ok-with-note] Data age is not stored. Every figure must show its filing year and read date (FR-64 → no AD requires either to be stored or carried through the seed). Suggested fix: AD-2 or AD-9 requires every register row to carry the filing year (from `regnskapsperiode`) and `read_at`, preserved through seed export and load.
- [ok-with-note] Withdrawn companies (`410 Gone`) are removed from stored data and the seed in v1 (FR-66 → TN "Licence obligations", AD-2 "Each table has exactly one writing step"). Step 1 deletes the company, but step-2 tables hold its fingerprint, its classification and other companies' stored explanations whose peer group included it. Suggested fix: migrations use `ON DELETE CASCADE` from step-2 tables to the company. After a removal, step 2 regenerates the default analyses and explanations that included the company, and the demo seed is re-exported.
- [ok-with-note] There is no fallback if the licence gate stays closed (FR-73 gate → AD-9 "Committing fingerprint categories waits for the licence gate"). If the gate stays shut, stage 4 cannot run in the demo seed for any company outside the allow-list. Both FR-73 and EXPERIENCE's outside-seed state assume it runs. Suggested fix: state the fallback in AD-9, e.g. stage 4 is skipped and the match basis drops a tier, reported in the funnel.
- [ok-with-note] The uncovered route has no tab segment (FR-4, EXPERIENCE `/analyse/{orgnr}` → AD-5 binds only `/analyse/{orgnr}/{fane}`). Suggested fix: AD-5 also covers `/analyse/{orgnr}`. A `{fane}` given for an uncovered company is dropped.
- [ok-with-note] The reader role's local credential has no stated source (FR-73 "No secret is needed to run v1 … a local default the Supabase CLI prints or optional" → AD-4 introduces a `reader` role with its own connection string). Suggested fix: say where the local `reader` credential comes from (a local-only default in `.env.example` or the migration). State that a hosted credential is never committed.
- [ok-with-note] Embeddings are v1 scope, cut last, yet listed under "Deferred" (FR-68 → TN Deferred "Embeddings (pgvector)"). The stack seed also lists `pg_trgm` and `unaccent` but not `pgvector`. Suggested fix: move embeddings to a cut-order note rather than "Deferred", and add `pgvector` to the stack seed.
- [ok-with-note] Latency after an adjustment (§7 "Performance", SM-5, FR-19 → AD-6 makes every exclude or widen a server round trip that reruns the funnel; caching is deferred). Nothing measures this latency. Suggested fix: add a latency check (demo A at the widest band step) next to SM-5.
- [ok-with-note] v1 segmentation is AS only (FR-9 "v1 covers `AS` only" → TN "Peer group", stage 3 says only "legal form"). Suggested fix: add "v1: AS only".
- [ok-with-note] The fingerprint categories in the demo seed include a personnel-cost band (FR-73 → TN "Running locally" demo bullet lists inventory, cost-of-goods band, capitalised intangibles and asset-intensity band, but no personnel-cost band). Suggested fix: add it to the TN list.

## 2. EXPERIENCE.md (`ux-designs/ux-Peerless-2026-10-04/EXPERIENCE.md`)

- [contradicts] Search typeahead (Component Patterns "Search results": combobox, 300 ms debounce, at most 8 results → AD-4 *"v1 has no open JSON endpoints: pages are rendered on the server"*). A debounced listbox needs a server action or route handler that returns result rows. That endpoint is also the cheapest harvesting surface: name, orgnr, industry and municipality for every seeded company. Suggested fix: AD-4 names search as the one data endpoint. It is a server action reading through `reader`, capped at 8 rows with a minimum query length, never returns financial fields, and is counted by AD-10.
- [contradicts] Bounds on the EV/EBIT multiple (Component Patterns "Multiple field": *"Accepts a number > 0 with up to one decimal"* → AD-5 "(0, 50] in steps of 0.1"). The field accepts 60; AD-5 then rejects it from the URL, so a reload silently empties it. Suggested fix: add the upper bound of 50 and its error copy to EXPERIENCE's field validation, or drop the bound from AD-5.
- [contradicts] Dropped exclusions. State Patterns "Invalid URL state" shows one notice, *"Noen innstillinger i lenken var ugyldige …"*, for any fallback, including an excluded orgnr not in the group. The memlog says such peers are "dropped silently". AD-5 says only "are dropped otherwise". Suggested fix: decide whether a dropped exclusion raises the notice. A dropped exclusion after a seed refresh is expected, which argues for silence, but EXPERIENCE says otherwise. Align AD-5, the memlog and EXPERIENCE.
- [ok-with-note] Encoding "Til medianen" in the URL. The closable-share control includes "Til medianen for driftsmargin (n %)", which is the exact s_med, not one of the numeric steps (Vocabulary, "Closable-share control" → AD-5 "share come from fixed lists"; AD-6 "exact 'to the median' share from the server"). Suggested fix: AD-5 lists a symbolic value (e.g. `median`) that the server resolves to exact s_med. Where s_med does not exist (r ≥ median), it falls back to 50 %.
- [ok-with-note] A nine-digit orgnr that fails modulus 11 ("Malformed number" and "Invalid URL state" define malformed as a digit count other than nine → AD-5 requires modulus 11). Neither the search field nor the URL has a state for nine digits that fail mod-11: the malformed message, or the not-found message with demo links. Suggested fix: add the state and its copy to EXPERIENCE, and have AD-5 point to it.
- [ok-with-note] Recompute pending and failure states. EXPERIENCE keeps previous figures dimmed with "Oppdaterer …"; on failure, *"figures and URL return to the last good state"* (State Patterns "Recompute (FR-19)" → AD-6 says "Excluding a peer or widening the band is a new URL and a server render"). A full page load cannot keep the old figures or revert the URL. Suggested fix: AD-6 says the new render is a client-side router transition (soft navigation with a pending state). On error, the router returns to the last good URL.
- [ok-with-note] Recompute location is still an open question in EXPERIENCE ("Open questions": *"Recompute location, for bmad-architecture"* → answered by AD-6). Suggested fix: close it in EXPERIENCE with a pointer to AD-6.
- [ok-with-note] Scope of the rate limit. The refusal state applies to "Any lookup" (State Patterns "Rate-limit refusal" → AD-10). Search fires every 300 ms while typing, and an adviser's office shares one IP. Suggested fix: AD-10 gives search and analysis renders separate budgets. Say whether exclude/widen renders count, and whether a refusal during a recompute uses the recompute-failure state or the refusal state.
- [contradicts] Explanation outside the demo seed (State Patterns "62.100 company outside the demo seed": *"no stored explanation → its statement"* → AD-7 says every 62.100 company has one). (See PRD item 1.)
- [ok-with-note] An explanation that fails FR-53 at seed load has no UI state (AD-7 *"an explanation that fails is not shown"* → EXPERIENCE has copy only for "no stored text"). Suggested fix: map it to "Det finnes ingen lagret forklaring for dette selskapet." or add its own copy. Log the failure at load.
- [ok-with-note] "No runtime filter" wording (AI marking "How the guard works in v1": *"there is no runtime filter"*, plus the about-page copy → AD-7 reruns FR-53 at seed load and hides failures, which is a load-time filter). Suggested fix: reword EXPERIENCE to "checked at generation, in tests and when the seed is loaded".
- [ok-with-note] What "the figures of the analysis" includes (beeswarm tooltips with peer revenue, provenance "Vis fordelingen" listing every peer value, excluded peers still listed → AD-4 *"the browser receives only the figures of the analysis it shows"*). This is consistent, but AD-4 should define the term to include all peers' values for every shown figure and the excluded rows, so a story does not trim them.
- [ok-with-note] The UI copy convention (Foundation: message files keyed by dotted ids, regenerated from the Vocabulary table; `lang="nb"`; light mode only; 320 px floor; WCAG 2.2 AA → no mention in TN). This is not an invariant by necessity, but it binds every UI story. Suggested fix: add one line to the stack seed or AD list pointing to EXPERIENCE "Foundation".
