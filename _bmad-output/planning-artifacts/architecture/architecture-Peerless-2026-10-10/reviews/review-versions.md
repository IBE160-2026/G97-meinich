# Review: versions and fit

Checked 2026-10-10 against the npm registry, GitHub and vendor docs. Nothing here comes from training data. Scope: the "Stack (seed, verified 2026-10-10)" line and every technology named in AD-1 to AD-11 of `technical-note-architecture.md`, plus AGENTS.md "Stack".

**Verdict: the stack fits every AD. There are no blockers.** Two version strings need changing: `.nvmrc` should move to 24.21.0, and Next.js needs the patched release due 2026-10-14. Four points need a decision when the project is set up: Cache Components, how share and EV are carried in the URL, bigint parsing in postgres.js, and pinning the Python version under uv 0.13.
